# 1. RÉSUMÉ EXÉCUTIF

## 1.1 Le Défi Mondial

| Indicateur | Valeur |
|------------|--------|
| Déchets générés mondialement | **2.3 milliards tonnes/an** |
| Projection 2050 | **3.8 milliards tonnes/an** |
| Déchets en décharge ou brûlés | **58%** |
| Déchets "non-récupérables" | **750-950 millions tonnes/an** |

**Le problème** : Les systèmes conventionnels échouent. Le recyclage ne capture que 13.5% des déchets mondialement. L'incinération détruit les matériaux et génère des émissions. La mise en décharge produit du méthane.

## 1.2 La Solution Urban Rig

**Technologie de pyrolyse continue à vapeur surchauffée** :
- Température : 600°C en atmosphère sans oxygène
- Pas de combustion = pas d'émissions de combustion
- Traite les déchets mixtes sans tri préalable
- Récupère 95%+ des matériaux (huile, carbone, métaux)

# 3. LA SOLUTION URBAN RIG

## 3.1 Technologie

### Processus de Pyrolyse Continue

```
    DÉCHETS          URBAN RIG           PRODUITS
       │                 │                  │
       ▼                 ▼                  ▼
  ┌─────────┐     ┌─────────────┐     ┌──────────┐
  │ Mixtes  │────▶│ Vapeur 600°C│────▶│  HUILE   │ 30-40%
  │ Plastiq │     │ Sans O2     │     │  CARBONE │ 15-20%
  │ Organiq │     │ Continu 24/7│     │  MÉTAUX  │ 5-10%
  │ Compos. │     │             │     │  SYNGAS  │ 10-15%
  └─────────┘     └─────────────┘     └──────────┘
```

### Spécifications Techniques

| Paramètre | Valeur |
|-----------|--------|
| Température opération | **600°C** |
| Atmosphère | **Sans oxygène (inerte)** |
| Mode | **Continu 24/7** |
| Capacité unitaire | **100 tonnes/jour** |
| Configuration CDG | **2 × 100T** |
| Durée cycle | **~4 heures/batch** |
