# Preuves internes : documents d'origine

Mis à jour le 14/10/2026. Ce dossier ne contient que des documents d'origine : documents remis par le constructeur (OneWorld Corporation), rapports d'essais, rapports remis à la préfecture de Chiba, documents fournis par des partenaires. Aucun texte rédigé avec ChatGPT ou Claude.

## Comment s'en servir

- Un document d'ici est cité par son identifiant de `working-folder/params/_evidence.yaml`, avec la page et la citation exacte.
- Le classement des sous-dossiers décrit la nature du document, pas son niveau de confiance. L'ancienne mention « preuves à 100 % » ou « à 90 % » est retirée : la fiabilité se juge document par document (règle 12). Un document du constructeur est une source commerciale. Le caractère indépendant d'un essai (qui a mesuré, avec quel laboratoire) est à établir pour chaque rapport.
- Le contenu de la plupart de ces documents n'a pas encore été inventorié page par page. Les descriptions ci-dessous viennent du nom des fichiers, sauf mention contraire.
- Plusieurs fichiers portent le nom « shiba » : il s'agit de la préfecture de **Chiba** (千葉県), d'après l'en-tête du rapport `documents-fournis/test data 2.docx`.
