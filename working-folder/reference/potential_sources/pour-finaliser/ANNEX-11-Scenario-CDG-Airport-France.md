# Annex 11 — Scenario Economics: Airport Waste — CDG (France)

**Purpose:** Full financial model for a URC-2000 deployment processing CDG airport waste. Combines the feedstock profile from Annex 6, pricing from Annex 3, equipment configuration from Annex 9 (including PRIMO), and country-level parameters from Annex 4A.

**Date:** March 2026
**Status:** PLACEHOLDER — to be completed when scenario modelling phase begins.

---

## Scope

This annex will contain:

1. **Feedstock parameters** — CDG airport waste composition (Annex 6), estimated ~30% plastic content, 140 T/day effective throughput
2. **Revenue projections** — Gate fees (airport premium vs municipal), oil, biochar, metals, carbon credits
3. **CAPEX** — Per Annex 9 §9.5.1 CDG configuration (~€67.0M, including PRIMO)
4. **OPEX** — Including any airport-specific compliance costs
5. **Energy balance** — Adapted to CDG feedstock composition
6. **P\&L, cash flow, and payback** — 15-year projection
7. **Sensitivity analysis**
8. **CDG-specific considerations** — International waste regulations (ICAO Annex 18, EU 1069/2009), ADP partnership structure, surrounding municipal catchment

**Reference:** Current financial model base case uses 30% plastic — close to CDG estimates.
