Values and content read

  • Pour injecter un méthane de synthèse dans le réseau de transport : H2 < 2 % molaire ; CO < 0,1 % ; CO2 < 2,5 % ; O2 < 0,01 % ; PCS gaz H 10,7 à 12,8 kWh/m3(n) ; Wobbe gaz H 13,64 à 15,7 kWh/m3(n). Le gaz de pyrolyse décrit (64,5 % H2, 3,0 % CO, 8,6 % CO2) est très loin de ces prescriptions : injection impossible sans méthanation et épuration complètes (comparaison de l'agent).
