Annex 2. Technical Evidence

Annex 2. Evidence sheets

Each figure of Annex 2 links to one of these sheets. Each sheet shows what the evidence supports, its confidence, and how the figure was obtained: the source document and page, or the formula and inputs of the calculation.

Confidence scale

ConfidenceApplies to
100 %Tests filed with the authorities, independent laboratory reports, legislation and reference data
95 %Manufacturer documentation (OneWorld), peer-reviewed literature, a laboratory report read in a reproduction, calculations on data at 95 % or more
90 %Calculations using a working assumption, a manufacturer table without printed author, patents
80 %Secondary sources

A calculation is never rated above its least reliable input, nor above 95 %.
