Values and content read

  • France 2024, déchets plastiques post-consommation collectés : 4 160 kt (46 % en mélange, 54 % en collecte séparée). Traitement : recyclage 23,1 % (964 kt, dont 313 kt recyclées à l'étranger), incinération 49,2 % (2 047 kt), stockage 27,6 % (1 149 kt). Par application : emballages 2 410 kt (recyclage 26,8 %, incinération 51,7 %, stockage 21,5 %) ; BTP 326 kt ; DEEE 285 kt ; ménager, loisirs et sport 210 kt ; automobile 185 kt ; agriculture 175 kt ; autres 569 kt. Exportations estimées 394 kt, importations 109 kt. Contenu recyclé post-consommation dans la transformation : 13,9 % (673 kt).
