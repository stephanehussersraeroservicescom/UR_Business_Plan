## 3. Technology & Process

### Pyrolysis Process Overview

Pyrolysis is a thermochemical decomposition process that breaks down plastic polymers at elevated temperatures (400-600 C) in the absence of oxygen.

```
INPUT                    PROCESS                 OUTPUT
+-----------+           +----------+           +-----------+
| Mixed     |           |          |           | Pyrolysis |
| Plastic   | --------> | PYROLYSIS| --------> | Oil (30%) |
| Waste     |           | REACTOR  |           +-----------+
+-----------+           |          |           | Biochar   |
                        | 400-600C |           | (18%)     |
                        | No O2    |           +-----------+
                        +----------+           | Metals    |
                                               | (7%)      |
                                               +-----------+
                                               | Syngas    |
                                               | (recycled)|
                                               +-----------+
```

### Process Steps

1. **Pre-treatment**: Sorting, shredding, and drying of input material
2. **Feeding**: Controlled introduction to reactor
3. **Pyrolysis**: Thermal decomposition at 400-600 C
4. **Condensation**: Vapor cooling to produce liquid oil
5. **Separation**: Recovery of char and metals
6. **Purification**: Oil quality enhancement

|---------|-----------|-------------|

| Continuous Operation | Yes | Often batch |
| Mixed Plastic Input | Yes | Limited |

### Output Products

#### 4.1 Pyrolysis Oil

- **Yield**: 30% of input mass (adjusted by plastic content in feedstock)
- **Quality**: Similar to crude oil, suitable for refinery feedstock
- **Applications**:
  - Feedstock for new plastic production (circular economy)
  - Fuel blending
  - Chemical industry raw material
- **Market Price**: 400-650 EUR/tonne

#### 4.2 Biochar

- **Yield**: 18% of input mass
- **Quality**: High carbon content, stable structure
- **Applications**:
  - Soil amendment
  - Carbon sequestration
  - Industrial adsorbent
  - Construction materials
- **Market Price**: 100-200 EUR/tonne

#### 4.3 Recovered Metals

- **Yield**: 7% of input mass
- **Types**: Aluminum, steel, copper from packaging
- **Applications**: Direct recycling to metal industry
- **Market Price**: 200-400 EUR/tonne

#### 4.4 Carbon Credits

- **CO2 Avoided**: 0.35 tCO2e per tonne of waste processed
- **Eligibility**: 50% of avoided emissions qualify for credits
- **Revenue**: Based on carbon market prices (currently 80 EUR/tCO2e)
